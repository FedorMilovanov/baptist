# Промты для GROK — генерация оставшихся изображений Milovi School

Файл подготовлен для замены оставшихся Unsplash-заглушек в `src/data/articles.ts`.

## Единые параметры для всех изображений

- **Размер:** `1280 × 800 px`
- **Соотношение сторон:** `16:10`, horizontal / landscape
- **Формат для сайта:** `WEBP`, quality 82–88
- **Путь сохранения:** `public/images/articles/{id}.webp`
- **Стиль:** premium French pâtisserie editorial, realistic food photography, soft natural window light, elegant warm beige / stone / ivory palette, shallow depth of field, refined magazine composition.
- **Важно:** без текста, без букв, без логотипов, без водяных знаков, без людей крупным планом, без узнаваемых реальных лиц шефов, без брендинга ресторанов.
- **Композиция:** главный объект по центру или слегка смещён по правилу третей; оставить немного чистого пространства по краям, чтобы картинка хорошо работала в карточках сайта.

## Универсальный negative prompt

Use this negative prompt for every generation:

```text
No text, no typography, no letters, no logo, no watermark, no brand packaging, no signature, no human face close-up, no celebrity likeness, no distorted food, no messy crumbs overload, no plastic look, no cartoon, no illustration, no AI artifacts, no extra fingers or hands, no low-resolution, no harsh flash, no oversaturated colors.
```
