# Карта русского баптизма · Russian Baptist History Map

**Интерактивный исследовательский прототип** по истории российского
евангельско-баптистского движения. React 19 · TypeScript · Vite 7 ·
Tailwind CSS 4 · Three.js / React Force Graph 3D.

**Status: working source-code prototype, not a fully verified historical edition
or a production deployment claim.** The repository contains application
source, data and UI components. Historical claims and interactive experiences
still require their own editorial and browser verification before publication.

## Что реализовано в исходном коде

По `src/App.tsx` и фактическим компонентам текущего `main`:

- три истока движения и интерактивная трёхмерная карта связей;
- хронология, события съездов, юридический контекст и параллельные временные шкалы;
- заметки региональной карты и карта исторических репрессий;
- организации, ключевые деятели, архивные заметки и исследовательские вопросы;
- таблицы сравнения, глоссарий и `QuizHub`;
- дополнительный интерфейс `AiAssistant`.

Существование компонентов **не доказывает** их корректность в каждом браузере,
верность всех данных, наличие публичного деплоя или качество ответов AI.
AI-помощник содержит локальные текстовые ответы и интеграцию с внешней моделью:
их утверждения требуют отдельных проверок источников.

## Структура и источники

- `src/App.tsx` — состав экрана;
- `src/components/` — пользовательские разделы, включая
  `MindMap3D.tsx`, `QuizHub.tsx`, `ResearchFindings.tsx`;
- `src/data/history/` — таблицы людей, движений, дат, архивов, правовых
  сведений, спорных биографий, справок об источниках;
- `src/data/quizData.ts` — вопросы викторины;
- `src/data/timeline.ts`, `src/data/organizations.ts` — хронология
  и организации.

**Редакционный статус:** записи в `src/data/` и компонентах могут содержать
вторичные ссылки, неполные локаторы или противоречащие друг другу даты.
Например, сопоставление фактов в локальных ответах AI с записями истории
требует отдельной сверки. Ни один отдельный URL или список источников не
означает, что конкретное историческое утверждение уже подтверждено по
полному первичному документу.

Для публикации спорных дат, имён, цитат и связей нужны оригинальный
источник, точный локатор, контекст и запись редакционного решения.
